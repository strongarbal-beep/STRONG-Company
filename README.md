## 🌐 2. اللغات ونظام الروابط والاتجاه

يدعم الموقع 3 لغات كاملة مع عناوين صفحات مستقلة (URLs):
* **العربية (`/ar/`):** اتجاه RTL كامل مع خطوط عربية واضحة ومتقنة. (اللغة الافتراضية).
* **الكردية السورانية (`/ku/`):** اتجاه RTL كامل مع دعم وعرض سليم لجميع الحروف الكردية (ێ، ۆ، ڕ، ڵ، ە، وو، پ، چ، ژ، گ).
* **الإنجليزية (`/en/`):** اتجاه LTR قياسي.
* **تحويل التوجيه التلقائي:** زيارة الرابط الرئيسي `/` تحوّل الزائر تلقائياً وبسلاسة إلى لغته المفضلة أو إلى العربية الافتراضية `/ar/`.
* **عزل اتجاه البيانات (Isolation):** تم ضبط البريد الإلكتروني وأرقام الموديلات والشفرات لتعرض باتجاه `dir="ltr"` الصارم حتى لا تتداخل داخل النصوص العربية أو الكردية.

## 🖼️ 3. نظام الصور الثابتة للمنتجات وكيفية إدارتها

صور الموقع والمنتجات منظمة داخل مجلد `public/images/` بالهيكلية التالية:

```text
public/
  images/
    logo/                # شعار الشركة (logo.svg)
    hero/                # الصورة والخلفية الرئيسية لقسم الهيرو (hero-bg.svg)
    about/               # صور المقر الرئيسي والمدير المفوض (company-building.svg, director.svg)
    banners/             # صور وبنرات الجودة والشراكات (banner-quality.svg, banner-partnership.svg)
    gallery/             # صور مرافق الشركة والعمليات
    products/            # صور المنتجات والكتالوج
      category-1/        # منتجات الفئة الأولى (product-101.svg, product-102.svg)
      category-2/        # منتجات الفئة الثانية (product-201.svg, product-202.svg)
      category-3/        # منتجات الفئة الثالثة (product-301.svg, product-302.svg)
```

### كيف تضيف أو تستبدل صور المنتجات قبل رفع الموقع للاستضافة؟
1. جهّز صور منتجاتك بصيغ الويب المدعومة: `JPG` أو `JPEG` أو `PNG` أو `WebP` أو `SVG`.
2. ضع ملفات الصور داخل المجلد المناسب، مثلاً: `public/images/products/category-1/my-item.jpg`.
3. يمكنك تعديل مسار الصورة في ملف `data/store.json` أو تركه وتعديله مباشرة من لوحة الإدارة بعد تشغيل الموقع بنقرة زر واحدة عبر ميزة "رفع صورة من جهازك" مع معاينة فورية!
4. جميع مسارات الصور نسبية ومحمية وتظهر تلقائياً بعد بناء نسخة الإنتاج (`Production Build`).

## 🔐 4. لوحة الإدارة الخاصة (Private Admin Dashboard)

* **رابط اللوحة:** `/admin`
* **صفحة تسجيل الدخول:** `/admin/login`
* **الحماية والأمان:**
  * المسار محمي بجدار ناري في `middleware.ts` ويمنع الوصول دون جلسة مشفرة (`JWT` في كوكيز `HttpOnly` آمنة).
  * كلمات المرور مشفرة بواسطة خوارزمية `bcrypt`.
  * حماية من هجمات التخمين (Rate Limiting) على مسار تسجيل الدخول ونموذج الاتصال.
  * التحقق الصارم من نوع وحجم الملفات المرفوعة (حتى 5 ميغابايت بصيغ صور الويب فقط).

### بيانات الدخول الافتراضية:
* **اسم المستخدم:** `admin`
* **كلمة المرور:** `StrongAdmin2026!#`
*(يمكنك تغيير كلمة المرور في أي لحظة من تبويب "الأمان وكلمة المرور" داخل اللوحة).*

### إمكانيات لوحة الإدارة:
1. **معلومات الشركة والهوية:**
   * تعديل اسم الشركة باللغات الثلاث.
   * تعديل اسم المدير المفوض باللغات الثلاث.
   * تعديل العنوان باللغات الثلاث.
   * تعديل البريد الإلكتروني ورقم الهاتف.
   * رفع واستبدال الشعار والصورة الرئيسية.
   * تعديل نصوص من نحن، الرؤية، الرسالة، والقيم باللغات الثلاث.
2. **إدارة المنتجات (كتالوج غير محدود):**
   * إضافة منتج جديد مع الاسم، الوصف، المواصفات الفنية، الرمز (SKU)، والفئة باللغات الثلاث.
   * رفع صور المنتجات مباشرة من الكمبيوتر مع معاينة فورية قبل الحفظ.
   * تعديل وحذف المنتجات.
   * إخفاء أو إظهار أي منتج للزوار بنقرة زر.
   * تغيير ترتيب ظهور المنتجات (تحريك لأعلى / لأسفل).
3. **صندوق رسائل واستفسارات الزوار:**
   * استعراض الرسائل والطلبات الواردة عبر الموقع مع التاريخ وبيانات المرسل.
   * زر مباشر للرد على العميل عبر البريد الإلكتروني.
   * حذف أو أرشفة الرسائل.
4. **حفظ التعديلات الدائم:**
   * يتم تخزين التعديلات فورياً وبشكل ذري (Atomic File Writing) في ملف البيانات `data/store.json` مع نسخة احتياطية `data/store.backup.json`، مما يضمن بقاء التعديلات بنسبة 100% بعد إعادة تشغيل السيرفر أو المتصفح.

## 🚀 5. متطلبات التشغيل والاستضافة

### المتطلبات الأساسية:
* **Node.js:** الإصدار 18 أو 20 أو أحدث.
* **مدير الحزم:** `pnpm` أو `npm`.

### أوامر التشغيل المحلية:
```bash
# تثبيت الحزم
pnpm install

# تشغيل بيئة التطوير
pnpm run dev

# بناء نسخة الإنتاج المحسّنة (Production Build)
pnpm run build

# تشغيل السيرفر الإنتاجي
pnpm start
```

### خيارات الاستضافة وتكاليفها:
1. **استضافة سحابية ذاتية (VPS / Cloud Server) — [الخيار الموصى به بدون أية تكاليف إضافية]:**
   * مثل: Hetzner أو DigitalOcean أو أي سيرفر Linux/Windows.
   * التكلفة: تكلفة السيرفر المعتادة (تبدأ من 4$ إلى 6$ شهرياً).
   * الميزة: يعمل الموقع ولوحة الإدارة مع تخزين الصور وقاعدة البيانات مباشرة على السيرفر دون الحاجة لشراء أو ربط خدمات خارجية.
2. **استضافة Docker:**
   * المشروع جاهز للتشغيل كحاوية Docker وتوصيل مجلدي `data` و `public/images` كـ Volumes لضمان بقاء البيانات والصور المرفوعة دائماً.
3. **استضافة Serverless (مثل Vercel):**
   * إذا اخترت النشر على Vercel، فنظراً لأن نظام الملفات في بيئات Serverless يكون Read-Only أثناء التشغيل، فإن المشروع يدعم بسهولة ربط قاعدة بيانات خارجية مثل **Supabase** المجانية أو PostgreSQL لحفظ البيانات و Supabase Storage لحفظ الصور دون تكلفة إضافية (ضمن الخطة المجانية 100%).

## 🔍 6. محركات البحث SEO
* عناوين ووصف خاص ومستقل لكل صفحة ولكل لغة (`Metadata`).
* خريطة موقع ديناميكية متكاملة: `/sitemap.xml`.
* ملف الفهرسة وتوجيه العناكب: `/robots.txt` (مع حظر أرشفة `/admin/`).
* روابط `canonical` وروابط التوافق اللغوي `hreflang` لجميع اللغات الثلاث (العربية، الكردية، الإنجليزية).
* صور محسّنة مع نصوص بديلة `Alt Text` بلغة الزائر.
